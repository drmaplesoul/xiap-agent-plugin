# Architecture Design 工作流

## 执行步骤

### 1. 需求收集
- 明确系统边界和核心用例
- 识别质量属性需求（性能、可扩展性、安全性、可维护性）

### 2. 架构分析
- 调用 `mcp__myplugin__code_analyze` 分析现有代码库结构
- 识别现有架构模式和瓶颈

### 3. 方案设计
- 基于 resources/clean-arch.ts 的整洁架构模板
- 选用合适的设计模式（参考 resources/design-patterns.ts）
- 绘制架构分层图、组件交互图

### 4. 输出交付
- 架构设计文档
- 关键模块接口定义
- 迁移路径（如为重构项目）
- 风险评估与缓解方案
