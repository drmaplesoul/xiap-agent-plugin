# Data Analyzer 技能包

## 可用技能
技能由系统 Hook 根据用户任务关键词自动匹配加载。

## 技能列表
| 技能 | 触发关键词 | 描述 |
|------|-----------|------|
| data-pipeline | ETL, 管道, 同步, 导入, pipeline | 数据处理管道构建 |
| stat-analysis | 统计, 分析, 回归, 聚类, statistics | 统计分析与建模 |
| dashboard | 报表, 看板, 可视化, dashboard, chart | 数据看板与图表 |
| data-quality | 质量, 清洗, 缺失, 异常, quality | 数据质量检测与清洗 |
